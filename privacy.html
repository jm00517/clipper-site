Privacy Policy

Pudding Clipper · Last updated: 2026-10-09

Who uses this tool

Pudding Clipper is used only by its operator to upload videos to the operator's own YouTube channels. It is not offered to the public and has no other users.

Information we access

When the operator signs in with Google, the tool receives an OAuth token for the operator's own channels with the scopes youtube.upload and youtube.readonly. It uses them only to upload the operator's videos and thumbnails and to read the status of those uploaded videos.

Storage

The OAuth token is stored only on the operator's personal computer, in a local file that is not uploaded or shared. Upload records (video ID, title, privacy setting, upload time) are kept locally on the same computer.

Sharing

No data is sold, shared or transferred to any third party. No analytics or advertising services are used. No data about other YouTube users is collected.

Google API Services

Pudding Clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google Account security settings: https://myaccount.google.com/permissions. Deleting the local token file also stops all access.
